# Шпаргалка по индексированию

- B-tree: выбор по умолчанию для равенства, диапазонов и упорядоченных сканирований.
- Composite: сопоставляйте ведущие колонки с фильтрами, а последующие колонки - с порядком сортировки или потребностями покрытия.
- Covering: включайте колонки в путь индекса, чтобы затрагивать меньше heap-страниц.
- Partial: индексируйте только строки, соответствующие стабильному предикату, например неоплаченные заказы.
- Expression: индексируйте вычисляемое выражение, например `lower(email)`.
- GIN: полезен для JSONB containment и lookup, похожих на работу с массивами.

Индексы не бесплатны. Они занимают место, замедляют записи и могут быть слишком специфичны для конкретного запроса.

В лаборатории храните гипотезы по индексам в `workspace/indexes/` и запускайте
их явно. Измеряйте эффект через `explain-file` и `benchmark-file`, а для
возврата к базовой схеме заново выполняйте seed.
