# Подсказки

- Проверьте, сколько products совпадают сразу по двум JSONB keys, а не только по `tier`.
- Сравните обычный GIN index и `jsonb_path_ops` для containment-only predicate.
- После индекса снова запустите `EXPLAIN (ANALYZE, BUFFERS)` и проверьте, изменился ли scan type.

Эти подсказки не раскрывают полный SQL предлагаемого решения. Используйте их, чтобы выбрать следующую проверку.
