# Official Solution Access

This directory is outside the default learner workflow. Open it only after you want to compare your own attempt with the maintained reference.

Files:

- `official-indexes.sql`: reference schema/index changes.
- `official-solution.sql`: reference query.
- `official-explain.txt`: captured evidence for maintainers.

Trade-offs to review: write overhead, extra storage, query specificity, maintenance cost, and cases where the approach may not help.
