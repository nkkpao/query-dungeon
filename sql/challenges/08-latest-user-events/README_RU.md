# 08 Последние события пользователя

Базовый план: пересоздайте командой make explain CHALLENGE=08-latest-user-events.

Бизнес-задача: показать последнюю ленту активности пользователя.

Подсказки: сравните предикат ленты с нужной сортировкой перед выбором пути доступа.

Компромиссы: покрывающая форма отлично подходит для этой ленты и менее полезна для глобальной аналитики событий.

Документация: см. `docs/how-to-explain.md`, `docs/indexing-cheatsheet.md` и `docs/query-optimization-workflow.md`.
