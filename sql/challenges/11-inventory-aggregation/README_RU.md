# 11 Ошибка агрегации запасов

Базовый план: пересоздайте командой make explain CHALLENGE=11-inventory-aggregation.

Бизнес-задача: найти продукты с наименьшим остатком на складе.

Подсказки: метрика запасов вычисляется до того, как несвязанный детальный JOIN раздувает промежуточные строки.

Компромиссы: удаление JOIN сохраняет метрику запасов, но отчет, которому действительно нужны измерения продаж на уровне позиций, должен агрегировать эти измерения отдельно.

Документация: см. `docs/how-to-explain.md`, `docs/indexing-cheatsheet.md` и `docs/query-optimization-workflow.md`.
