# 05 Поиск email без учета регистра

Базовый план: пересоздайте командой make explain CHALLENGE=05-lower-email-expression-index.

Бизнес-задача: найти пользователя по email независимо от регистра.

Подсказки: функция на колонке может помешать использованию обычного индекса.

Компромиссы: expression-индексы специфичны к форме запроса.

Документация: см. `docs/how-to-explain.md`, `docs/indexing-cheatsheet.md` и `docs/query-optimization-workflow.md`.
