# 03 Последний платеж через коррелированный подзапрос

Базовый план: пересоздайте командой make explain CHALLENGE=03-latest-payment-correlated-subquery.

Бизнес-задача: показать последнее состояние платежа для недавних неотмененных заказов.

Подсказки: повторяющиеся подпланы - это запах; проверьте, можно ли превратить два коррелированных lookup в один lateral lookup.

Компромиссы: эталонный индекс добавляет накладные расходы на запись в payments, но поддерживает чтение последнего платежа по заказу.

Документация: см. `docs/how-to-explain.md`, `docs/indexing-cheatsheet.md` и `docs/query-optimization-workflow.md`.
