# 09 Частичный индекс для неоплаченных заказов

Базовый план: пересоздайте командой make explain CHALLENGE=09-unpaid-orders-partial-index.

Бизнес-задача: разбирать недавние неоплаченные заказы по приоритету.

Подсказки: проверьте, сколько строк соответствует статусу и не является ли доступ через всю таблицу расточительным.

Компромиссы: частичные индексы компактны, но пользу получают только запросы, совпадающие с предикатом.

Документация: см. `docs/how-to-explain.md`, `docs/indexing-cheatsheet.md` и `docs/query-optimization-workflow.md`.
